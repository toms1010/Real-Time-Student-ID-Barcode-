# ---------------------------------------------------------------------------
# Runtime dependencies for the Python side of the system.
#
# Install into a virtual environment:
#   python3 -m venv .venv
#   source .venv/bin/activate
#   pip install -r requirements.txt
#
# Version policy
# --------------
# Constraints are ranges with an upper major bound rather than exact pins so
# that a wheel exists for every Python the project supports (3.11 - 3.14).
# requirements-lock.txt records the exact versions this project was verified
# with; use it for a reproducible deployment:
#
#   pip install -r requirements-lock.txt
#
# Every package is available as a wheel from PyPI (or, for zxing-cpp on an
# interpreter without a prebuilt wheel, builds from its sdist with cmake +
# a C++17 compiler).  Nothing needs root, the internet, or a cloud service at
# runtime.
# ---------------------------------------------------------------------------
